About OpenDash

OpenDash is a free and open-source game inspired by Geometry Dash, created by Voxel Team Games.

The project has no goal of making a profit. Ports, modifications, forks and community-created content are welcome.

OpenDash is designed to be moddable and customizable, giving the community the freedom to create new content and experiment with the game.

🔓 Open Source

The source code is publicly available. Fork it, modify it and create your own version.

Built for the Community

OpenDash is intentionally open. You can create ports, forks, modifications, new levels, new mechanics and other projects based on it.

The assets included with the project can also be used as a starting point for creating new content.
